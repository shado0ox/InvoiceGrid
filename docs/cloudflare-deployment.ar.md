# نشر InvoiceGrid للمحاسبين — مفتاح شخصي لكل مستخدم

هذه النسخة عامة بلا تسجيل أو قاعدة بيانات أو أرشيف. Cloudflare يخدم ملفات الواجهة فقط؛ القراءة تتم مباشرة من متصفح المحاسب إلى Gemini باستخدام مفتاح المحاسب. التعديل وإنشاء Excel يحدثان داخل المتصفح. لا يحتاج النشر إلى Orange Pi أو Docker أو Tunnel.

## الاستخدام

1. يفتح المحاسب رابط الموقع ويضغط «إضافة مفتاحي».
2. ينشئ مفتاحًا من https://aistudio.google.com/apikey، ويضيفه مع اسم نموذج متاح في حسابه يدعم الصور وPDF وإخراج JSON.
3. يوافق على إرسال المستندات إلى Google وعلى استهلاك حسابه، ثم يستخدم المفتاح للجلسة.
4. يرفع PDF / JPG / PNG / WebP حتى 6 MB لكل ملف، يراجع البيانات مع الأصل، ثم ينزّل Excel.

المفتاح والنتائج في ذاكرة الصفحة فقط، ولا يرسلان إلى سيرفر الموقع ولا يحفظان في localStorage أو قاعدة بيانات. مسح المفتاح متاح من الصفحة؛ تحديثها أو إغلاقها يتطلب إعادة إدخاله. أنشئ مفتاحًا مخصصًا للأداة ولا تستخدم جهازًا مشتركًا. بيانات المستندات تُعالج لدى Google وفق سياسة حساب المستخدم. الحصص والتكلفة تخص حساب المستخدم، ولا توجد حصة مجانية مضمونة من الموقع. اللغة والعداد المحلي فقط يُحفظان؛ العداد ليس رصيد المزوّد.

نزّل Excel قبل الإغلاق. التحذير لا يضمن إظهاره كل متصفحات الهاتف، ولا يضمن اكتمال تنزيل الملف. تعدد العملات ينتج ورقة لكل عملة بنفس الأعمدة التسعة وترتيب الصفوف داخل العملة؛ CSV ونسخ الجدول يحتاجان عملة واحدة. البحث يصدّر النتائج الظاهرة فقط.

## النشر من كمبيوترك

بعد دمج التغييرات، استخدم Node.js 22.12 أو أحدث:

```bash
git clone https://github.com/shado0ox/InvoiceGrid.git
cd InvoiceGrid
npm ci
npx wrangler login
npm run deploy
```

لا تضف GEMINI_API_KEY أو مفاتيح المستخدمين إلى إعدادات Cloudflare أو مستودع GitHub. لا يوجد مفتاح استضافة احتياطي؛ مسار القراءة القديم `/api/extract-invoice` يرجع 410 ولا يرسل طلبًا للمزوّد.

## ربط الدومين

1. أضف دومينك إلى Cloudflare مع الحفاظ على DNS وسجلات التطبيقات الأخرى.
2. افتح **Workers & Pages → invoicegrid → Settings → Domains & Routes → Add → Custom Domain**.
3. أدخل الدومين الفرعي المطلوب مثل `invoices.xshadox.com`. Cloudflare يجهز DNS وHTTPS، دون توجيه هذا الدومين إلى Orange Pi.
4. هذه النسخة لا تحتاج Cloudflare Access. إذا فعّلت حماية البريد الخاصة بالنسخة السابقة، أزل تطبيق Access الخاص بهذا الدومين ليصبح متاحًا للمحاسبين. احذف أسرار Gemini ومتغيرات Access القديمة من Worker إن كانت مضافة.

`workers_dev` وPreview URLs معطّلان؛ الاستخدام يكون عبر الدومين الذي تربطه. لم يتم ربط دومين فعلي من هذا المستودع.

## التحديث التلقائي

اربط GitHub من **Worker → Settings → Builds**: البناء `npm ci && npm run build`، والنشر `npx wrangler deploy`، وفرع النشر `main`. يُنشر تحديث الواجهة بعد دمجه، بدون بناء على Orange Pi.

أو حدّث من كمبيوترك:

```bash
git pull --ff-only
npm ci
npm run deploy
```

يمكن اختيار خطة Cloudflare المناسبة ضمن حدودها؛ هذه النسخة تعتمد على الملفات الثابتة ولا تشغّل OCR على Worker. تكاليف Gemini مستقلة وتخص كل محاسب.

## اختبار قبل مشاركة الرابط

- افتح نافذة خاصة: يجب أن يظهر الموقع بدون تسجيل.
- بدون مفتاح، الرفع يطلب إعداد المفتاح ولا يرسل طلب قراءة.
- بمفتاح تجريبي حقيقي، اقرأ صورة وPDF وراجع الأعمدة والأرقام الضريبية وتصدير Excel.
- من أدوات المتصفح، تأكد أن القراءة تستهدف `generativelanguage.googleapis.com`، وليس `/api/extract-invoice` على موقعك.
- تحقق أن إعادة تحميل الصفحة تمسح المفتاح والنتائج، وأن زر مسح المفتاح يمنع قراءة جديدة.

التحقق البرمجي: `npm run lint`، `npm test`، `npm run build`، `npx wrangler deploy --dry-run`. اختبارات المزوّد تستخدم استجابة وهمية؛ نجاح القراءة الفعلية يعتمد على مفتاح المستخدم وصلاحياته والنموذج وحصته.

## القراءة المحلية واستكمال الفواتير

يقرأ البرنامج QR السعودي ثم النص الموجود داخل PDF محليًا قبل طلب Gemini. المفتاح اختياري لهذه القراءة؛ الصفحات التي لا تُقرأ تبقى في الجدول للإكمال اليدوي بجانب الأصل، حتى عند نفاد الحصة. المبالغ غير المعروفة تبقى فارغة في Excel. QR لا يوفر عادة رقم الفاتورة أو تفاصيلها، ولا يمثل فكّه تحققًا من التوقيع الإلكتروني. راجع البيانات ثم صدّرها قبل إغلاق الصفحة.

بعد دمج التحديث، من مجلد المشروع في PowerShell:

```powershell
git pull --ff-only
npm ci
npm run deploy
```

احتفظ بإعدادات حسابك والدومين في `wrangler.jsonc`؛ هذا التحديث لا يغيّرها.
